# 프롬프트 엔지니어링 참조 자료

prompt-designer 스킬의 상세 근거 자료. SKILL.md 절차 실행 중 특정 기법의 정의·효과나 모델별 원칙이 필요할 때만 참고한다.

---

## 1. 프롬프트 구성의 핵심 13요소

### A. 시스템 설계 관점 (Architecture)

- 프레임워크(설계): 역할부여(Persona), 맥락제공(Context), 조사방식 및 대상
- 알고리즘(로직): 작업 분해 및 추론 제어, 반복적 탐색(Iterative), Prompt chaining, 구체적 요청
- 인터페이스(QA): 구분기호 활용, 답변형태와 형식, 어조 및 스타일, 예시제공(Few-shot), 질문시키기

### B. 인지 부하 제어 관점 (Psychology)

- 제약조건(Constraint): 사고 범위의 제한(가드레일). 오류 방지 및 규격 준수 목적.
- 가이드(Guidance): 사고 경로의 유도(내비게이션). 품질 향상 및 추론 보조 목적.
- 상호작용(Interaction): 질문시키기, Prompt chaining을 통한 피드백 루프 생성.

## 2. 고급 기법 정의·효과

| 기법 | 정의 | 효과 |
|---|---|---|
| OPRO (Optimization by PROmpting) | AI에게 특정 과제 수행을 위한 최적의 프롬프트를 직접 설계하도록 지시 | 인간이 인지하지 못한 모델 최적화 지시 구조 발견 |
| Task Decomposition & Reasoning Control | 복잡한 문제를 하위 과업으로 구조화하되 상세 내부 사고과정 출력을 강제하지 않음. 모델이 지원하면 Reasoning Effort/Thinking Level 등 네이티브 추론 우선 | 불필요한 CoT 지시를 줄이고 추론 모델의 자체 추론 능력 활용 |
| CoVe (Chain-of-Verification) | 초안 생성 → 검증 질문 추출 → 독립적 팩트체크 → 최종 수정 | 할루시네이션 억제, 신뢰도 향상 |
| Multi-Agent Debate | 서로 다른 전문가 페르소나가 내부에서 토론해 합의안 도출 | 단일 모델 편향성 극복, 다각도 리스크 검토 |
| Evidence Request(근거요청) | 모든 주장·수치에 출처와 논리적 근거를 명시하도록 강제 | 정보 투명성 확보, 사용자 교차 검증 용이 |
| Self-Evaluation & Rubric | 명확한 평가 기준을 주고 AI가 자신의 답변을 스스로 채점·비평 | 주관적 답변 객관화, 비즈니스 요구사항 충족 |
| Self-Correction | 작성된 초안을 스스로 비판적으로 읽고 논리 모순·가독성 개선 | 외부 피드백 없이 결과물 완성도 상향 |

## 3. 모델별 프롬프팅 원칙

- GPT 계열: 목표·성공기준·제약조건을 명확히 제시하고 불필요한 단계별 사고 지시는 줄인다. 복잡한 작업은 Reasoning Effort를 활용한다.
- Gemini 계열: 직접적이고 간결한 지시를 우선한다. 장문 자료는 먼저 제공하고 구체적 질문·과업을 뒤에 배치한다.
- Claude 계열: 역할·맥락·제약·출력 형식을 구조화해 제시한다. Adaptive Thinking을 활용하고 불필요하게 상세한 사고 과정을 강제하지 않는다.
- Grok 계열: 최신 정보가 필요한 작업은 Web/X Search 사용을 명시한다. 복잡한 작업은 추론 수준과 도구 활용 조건을 함께 설계한다.

모델명·컨텍스트 크기·API 파라미터는 빠르게 변경되므로, 사용자가 특정 모델을 지정하고 해당 정보가 중요할 경우 최신 공식 문서를 우선 확인한다.

---

## 4. 컨텍스트 관리 전략

- 구조화: 역할, 목표, 맥락, 제약조건, 작업, 출력형식을 명확하게 구분한다.
- 정보 배치: 역할·목표·핵심 제약 등 안정적인 지침은 앞쪽에, 긴 참고자료가 있으면 자료 이후에 최종 질문·수행 과업을 재제시한다.
- 맥락 증류: 긴 대화는 핵심 사실·결정사항·제약조건 중심으로 압축한다.
- 토큰 관리: 글자 수·페이지 수를 고정 토큰값으로 환산하지 않는다. 토큰 수는 모델·토크나이저에 따라 달라진다.

---

## 5. 특수 활용 시나리오

### 질문시키기의 메타인지 활용

사용자가 모르는 사각지대(조하리의 창)를 AI의 역질문으로 탐색한다. 소크라테스식 대화로 사용자의 고정관념(전제)을 파괴하고 메타인지를 강화한다.

### EmotionPrompt의 고도화

모델의 주의력(Attention) 가중치를 재할당하도록 심리적 가치를 부여한다. 단순 아부가 아니라 "사회적 책임"이나 "기술적 난제"를 제시해 연산 자원 투입을 극대화한다. 남용하지 않고 과업 특성상 필요할 때만 적용한다.
