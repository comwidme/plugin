# Prompt Designer

이용자가 원하는 프롬프트를 새로 설계하거나, 기존 프롬프트를 전문가 수준으로
고도화해주는 플러그인입니다. OPRO, Task Decomposition, CoVe, Evidence
Request 등 프롬프트 엔지니어링 기법을 상황(난이도·오류 비용·최신성 요구)에
맞게 선별 적용합니다.

## 구성 요소

| 컴포넌트 | 개수 | 설명 |
|---|---|---|
| Skills | 1 | `prompt-designer` — 목적/AI 환경/평가기준을 파악해 신규 프롬프트를 설계하거나 기존 프롬프트를 고도화 |
| Agents | 0 | 사용하지 않음 |
| Hooks | 0 | 사용하지 않음 |
| MCP | 0 | 사용하지 않음 |

## 사용 방법

`/prompt-designer`로 직접 호출합니다 (자동 호출 없음).

1. 새로 설계할 때는 목적을 설명합니다.

   > /prompt-designer 신제품 보도자료 초안을 쓰는 프롬프트를 만들어줘

2. 기존 프롬프트를 고도화할 때는 프롬프트 원문을 그대로 붙여넣습니다.

   > /prompt-designer [기존 프롬프트 전문]

3. 질문 없이 판단으로 채운 항목(AI 환경 등)이 있으면, 최종 프롬프트 전에
   가정 내용을 먼저 보여주고 진행 여부를 확인합니다. 결과 구조에 영향을 주는
   항목(적용 대상 등)은 명시적으로 확인 질문을 합니다.
4. 최종 프롬프트는 항상 코드블록으로, 평어체 문장으로 제공됩니다.
