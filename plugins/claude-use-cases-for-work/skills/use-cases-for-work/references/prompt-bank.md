# 업무 유형별 프롬프트 뱅크

각 업무 유형마다 예시 프롬프트를 제공한다. 실제 테이블을 만들 때는 이 예시를
그대로 복사하지 말고, 사용자가 알려준 회사/직무/프로젝트 정보로 구체화해서
사용한다.

## ✍️ 글쓰기 (보고서, 이메일, 기획서)

- 🟢 `[프로젝트명] 관련 주간 업무 보고서 초안을 작성해줘. 이번 주 진행 상황은
  [내용]이고, 다음 주 계획은 [내용]이야. 상사에게 보고하는 톤으로, 핵심만
  간결하게 정리해줘.`
- 🟢 `[상대방]에게 보낼 협업 요청 이메일을 써줘. 목적은 [목적]이고, 정중하지만
  명확하게 요청 사항을 전달하고 싶어.`
- 🔵 `[신규 서비스/프로젝트]에 대한 기획서 초안을 작성해줘. 배경, 목표, 실행
  방안, 예상 리스크, 일정을 포함한 구조로 만들고, 각 섹션마다 근거가 필요한
  부분은 표시해줘.` (Artifacts로 문서 파일 생성)

## 📊 데이터 분석 (.csv, .xlsx)

- 🟢 `첨부한 [파일명] 데이터에서 [지표]의 월별 추이를 요약하고, 눈에 띄는
  이상치나 패턴이 있으면 짚어줘.`
- 🔵 `첨부한 매출 데이터를 분석해서 상위/하위 카테고리를 찾아내고, 다음 분기
  전략에 참고할 만한 인사이트 3가지를 제안해줘. 표와 함께 정리해줘.` (파일
  업로드 + 데이터 분석)

## 🧠 아이디어 발상 / 브레인스토밍

- 🟢 `[주제]에 대한 아이디어를 10개 브레인스토밍해줘. 실현 가능성과 예상
  효과를 기준으로 우선순위도 매겨줘.`
- 🔵 `[문제 상황]을 해결할 방법을 여러 각도(비용, 시간, 리스크)에서 깊이
  검토해서 3가지 대안을 비교 분석해줘.` (확장 사고)

## 📈 전략 및 기획

- 🔵 `[제품/서비스]의 시장 진입 전략을 SWOT 분석과 함께 세워줘. 경쟁사
  대비 차별점과 초기 3개월 실행 로드맵도 포함해줘.` (확장 사고)
- 🔵 `[캠페인/프로젝트]에 대한 최신 시장 동향과 경쟁사 사례를 조사해서
  전략 수립에 참고할 리포트를 만들어줘.` (Research)

## 📄 문서 요약 (PDF 포함)

- 🟢 `첨부한 PDF 보고서의 핵심 내용을 5줄로 요약해줘. 숫자와 결론 위주로
  정리해줘.`
- 🟢 `첨부한 계약서/제안서에서 우리 쪽에 불리할 수 있는 조항이 있는지
  짚어줘.`

## 🖼️ 이미지 / 스크린샷 분석

- 🟢 `첨부한 스크린샷(대시보드/차트)을 보고 핵심 수치와 트렌드를 설명해줘.`
- 🟢 `첨부한 경쟁사 광고 이미지를 분석해서 메시지 전략과 디자인 특징을
  정리해줘.`

## 🎓 학습 및 스킬 향상

- 🟢 `[업무 관련 개념/툴]을 실무자 입장에서 이해하기 쉽게 설명해줘. 예시도
  함께 들어줘.`
- 🔵 `[새로운 업무 프로세스]를 익혀야 하는데, 단계별 학습 계획을 짜줘. 매주
  실습할 과제도 포함해줘.`

## 💻 개발 업무 (해당되는 경우)

- 🔵 `[기능/버그]에 대한 코드를 작성/리뷰해줘. [언어/프레임워크] 기준으로,
  주석과 함께 설명해줘.` (Claude Code)

## 🔁 반복 업무 자동화

- 🔵 `매주 월요일 오전에 [정기 보고서/체크리스트]를 자동으로 만들어주는
  작업을 예약해줘.` (예약 작업/Skills)
