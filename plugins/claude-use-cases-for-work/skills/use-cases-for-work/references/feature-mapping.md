# ChatGPT ↔ Claude 기능 매핑

원본 GPT("ChatGPT Use Cases for Work")가 언급하는 ChatGPT 기능들을 Claude의
대응 기능으로 치환할 때 사용하는 표. 프롬프트의 "활용 Claude 기능" 칸을 채울
때 이 매핑을 기준으로 삼는다.

| ChatGPT 기능 / 사용 사례 | 대응하는 Claude 기능 | 설명 |
|---|---|---|
| 기본 채팅 응답 | 일반 대화 | 별도 기능 없이 바로 답변 |
| Deep Research (리서치 자동화) | Research (웹 검색 기반 심층 리서치) | 여러 출처를 탐색해 종합 리포트 생성 |
| ChatGPT Agent (업무 자동화) | Skills + Cowork 파일 작업 / 예약 작업(스케줄) | 반복 업무를 스킬로 만들거나 예약 실행으로 자동화 |
| Codex (개발 업무) | Claude Code / 코드 생성·리뷰 | 코드 작성, 디버깅, 리팩터링 |
| 파일 업로드 분석 (csv, xlsx) | 파일 업로드 + 데이터 분석 (xlsx 스킬) | 표 데이터 정리, 피벗, 차트 생성 |
| PDF 요약 | 파일 업로드 + 문서 요약 (pdf 스킬) | 긴 문서 핵심 요약, 표 형태 정리 |
| 이미지/스크린샷 분석 | 비전(이미지 인식) | 스크린샷, 사진, 차트 이미지 해석 |
| 복잡한 추론/기획 | 확장 사고 (Extended Thinking) | 다단계 논리, 전략 수립처럼 깊은 사고가 필요한 작업 |
| 문서/보고서 산출물 생성 | Artifacts (문서/슬라이드/스프레드시트 파일 생성) | 채팅 밖에서 바로 쓸 수 있는 완성 파일로 출력 |
| 대시보드/도구 제작 | Artifacts (인터랙티브 웹 페이지) | 계산기, 트래커 등 재사용 가능한 도구 제작 |
| 반복 리마인더/정기 보고 | 예약 작업 (스케줄) | 매주/매일 자동 실행되는 작업 설정 |

## 사용 지침

- 표를 만들 때 "고급 활용" 프롬프트에는 위 매핑에서 Deep Research → Research,
  Agent → Skills/예약 작업, Codex → Claude Code 대응 항목을 우선적으로
  사용한다.
- 사용자가 명시적으로 다른 매핑을 요청하면 그 지시를 따른다.
